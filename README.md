# Asistente Virtual con IA para Agencia de Lotería

## Descripción
Este proyecto implementa un asistente virtual inteligente impulsado por IA para automatizar la atención al cliente en una agencia de lotería. El sistema procesa consultas y jugadas realizadas a través de WhatsApp, calcula montos totales, y registra automáticamente toda la información en una base de datos en Notion.

## Tecnologías Utilizadas
- n8n: Orquestador de flujos de trabajo y automatización.
- Claude (Anthropic): Modelo de IA para procesamiento de lenguaje natural y toma de decisiones.
- Z-API Omni: API para la integración y envío de mensajes en WhatsApp.
- Notion: Base de datos para el registro y gestión de jugadas.

## Beneficios del Sistema
- Optimización del Tiempo: Al delegar la atención de los mensajes de WhatsApp a la IA, el operador puede concentrarse al cien por cien en la atención presencial y telefónica, reduciendo drásticamente los tiempos de espera y la carga de trabajo.
- Eficiencia Operativa: Registro automático y sin errores de los datos de cada cliente, números de la jugada, juego seleccionado y monto del ticket.
